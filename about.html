About this project

Web Test is a simple browser and operating system test site for emulated, virtualized, restored, and modern operating systems.

Compatibility target

The baseline is HTML 4.01 Transitional, CSS 1/2-style layout, standard GIF/JPEG/PNG files, and JavaScript written in an ES3-friendly style. Unsupported decoration should fail harmlessly.

UsedIntentionally avoided
Headings, tables, forms, links, images, floats, basic DOMFrameworks, modules, build tools, web fonts, SVG, canvas, fetch, promises
Explicit .html linksClient-side routing and JavaScript-only navigation
System fonts and same-origin assetsThird-party CDNs and external dependencies

This makes the project useful as both a real mini-site and a quick diagnostic tool.

Built with plain HTML, conservative CSS, and ES3-style JavaScript. No framework, web font, SVG, canvas, fetch, or cookies required.
