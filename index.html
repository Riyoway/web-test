One site, many eras

Open this page from classic Mac OS, early Windows, Linux, mobile devices, virtual machines, or a modern browser. The core page intentionally uses web technology that remains understandable to very old browsers.

Progressive compatibility: old browsers receive a clean, usable page; newer browsers add rounded corners, shadows, responsive sizing, and richer diagnostics.
