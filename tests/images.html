FormatImageExpected result
GIF89aA small indicator moves from left to right.
JPEGA blue gradient with readable labels.
PNGA checker pattern and a semi-transparent circle on capable browsers.
Missing imageThe alternative text or a broken-image indicator appears.

Some very old browsers have incomplete alpha transparency support for PNG. Showing the image without smooth transparency is still a useful result.

Built with plain HTML, conservative CSS, and ES3-style JavaScript. No framework, web font, SVG, canvas, fetch, or cookies required.
